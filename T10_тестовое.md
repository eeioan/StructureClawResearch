# Тестовое задание: «Сценарный бенчмарк для LLM-агентов, работающих с инженерным ПО»

Руководитель: Барахсин Г. М. (Telegram @barakhsin)

## Задание

Возьмите один из бенчмарков ниже (или найдите другой, где агент работает с инженерной программой и результат проверяется программно) и придумайте для него **один сценарий**: задачу, которую получает агент, и золотые шаги решения с чекпоинтами.

Бенчмарки на выбор:
- RestoreBench — восстановление сходимости расчёта потокораспределения: https://arxiv.org/abs/2609.00384
- StructureClaw — расчёт строительных конструкций (OpenSees): https://arxiv.org/abs/2607.14896
- Modelica Agent Workflow Benchmark (Pufibara) — моделирование физических систем: https://arxiv.org/abs/2608.23653
- SpreadsheetBench 2 — работа с таблицами: https://arxiv.org/abs/2606.29955
- Power Systems Agent Benchmark — задачи электроэнергетики: https://arxiv.org/abs/2606.20950

Формат и глубину проработки выбирайте сами. Если что-то в задании непонятно — спрашивайте, это нормально и приветствуется.
